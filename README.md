# Contact Manager

A small C practice project for learning how structs, arrays, functions, and user input can work together.

## Objective

The goal of this project is to move from manually creating records to allowing the user to enter and manage information about people.

## What I Am Practicing

- `struct`
- Arrays of structs
- Functions
- Function declarations and definitions
- Passing data to functions
- User input
- Tracking the number of active records
- Using `strcmp()` / string handling where necessary
